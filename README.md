This project implements an end-to-end machine learning pipeline for heart disease prediction, including data preprocessing, model training with scikit-learn, experiment tracking with MLflow, and CI/CD automation using GitHub Actions. The training workflow evaluates multiple RandomForest configurations and enforces a minimum accuracy threshold as a quality gate before allowing deployment. The project also includes automated drift monitoring using Evidently, which compares training (reference) data against simulated production data, generates an HTML drift report, and fails the pipeline if data drift exceeds a defined threshold. All experiments and artifacts are tracked locally via MLflow, while tests and training are executed automatically in CI to ensure reproducibility and model reliability.
